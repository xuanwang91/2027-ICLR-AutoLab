# AUTOLAB website preview
Static, responsive website based on the uploaded ICLR 2027 AUTOLAB Overleaf proposal. Open `index.html` locally to preview.

## GitHub Pages
Upload `index.html` to the root of a GitHub repository, then enable GitHub Pages in Settings > Pages, deploy from main / root. This does not publish automatically.

## Before publication
Confirm speaker permissions, organizer affiliations, shared-task wording, dates and links. Replace initials with licensed headshots if desired. Update pre-acceptance wording after any acceptance.
